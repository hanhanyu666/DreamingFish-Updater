DreamingFish 管理端桌面版 0.2.7（Windows x64）

先把压缩包里的整个“梦鱼更新管理”文件夹解压到固定位置，再双击里面的 DreamingFishAdminDesktop.exe，选择本机管理或远程连接。
不要直接在压缩包里运行，也不要只拿出 exe。
程序内置 Java，无需另外安装 Java。Windows 使用系统 WebView2；安装版会在缺少 WebView2 时联网安装。

本机管理
连接记录、运行日志和默认管理数据优先保存在本文件夹的 data；不可写时回退 AppData，连接页显示实际位置。根内相对连接可随整个便携文件夹搬迁，外部目录需单独保存 / 重新定位。请不要删除数据。
以前版本的 AppData 数据会尝试迁移；先记录、复制核对再切换，失败说明实际根和待清理材料，不承诺无残留。
也可选择已有管理端目录，继续使用原项目、账户、密钥与发布记录。
这里选择的是管理端目录，包含 management-settings.json 和 data；整合包源目录在项目中设置。

远程连接
填写 HTTPS 管理地址或已有的本机转发地址。也可填写系统 OpenSSH 中已有的配置名称与服务器管理端口。
SSH 连接使用已有配置和认证代理，保留主机密钥检查；第一次连接请先在正常 SSH 中确认主机身份。
账户登录仍在管理工作区进行，连接记录不保存密码或私钥。

关闭与退出
自绘标题栏支持拖动、最小化和最大化；工作区顶部“连接”可以返回连接选择页。
关闭窗口会收到系统托盘，后台任务和所属下载服务继续运行。托盘可返回工作区或重新选择连接。
明确退出会停止桌面端所属的本机服务或 SSH 通道，不停止其他管理端进程；远程服务器继续运行。

上传与部署
左侧选择项目与目录，中间浏览文件，右侧设置所选内容的维护方式。双击文件夹进入，工具栏提供后退、前进和返回上一级。
“导入文件”使用这台电脑的文件，旁边菜单提供文件夹和服务器导入。任务面板先上传并检查，再确认导入。
改动与版本用于发布、查看历史和恢复操作；发放用于部署包与玩家端程序；玩家端设计提供真实实时预览。
本机与远程使用同一套桌面界面。旧基本连接支持 0.2.1 或更新；稳定导入恢复与异步任务还要求 API v2 对应能力，旧下载不自动获得本轮修复。

有新版本时，连接页会提示并打开下载页。更新时退出程序，用新压缩包里的文件替换程序文件，保留 data 文件夹。
不要把自己的 data、管理账户或项目密钥放入公开程序包。

本地修复候选（尚未正式发布）
浏览器 / 渲染退出与无响应按每窗口一分钟三次共同限额恢复，达到上限后从托盘手动重建。断开取消所属网络工作，不撤销服务器已提交结果。
管理 JVM 默认堆 64–512 MiB，DFS_JAVA_HEAP_MB 只接受 128–16384 的整数；总内存还包括桌面与 WebView。
加密备份只恢复发布能力，不含源文件、运行设置、账户、桌面连接或导入恢复材料。完整搬迁同时保存实际 data / home 和外部目录。
