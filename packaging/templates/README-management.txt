DreamingFish 管理端 Windows x64

本包自带 Java 21 运行时，不需要另外安装 Java。建议在 PowerShell 中进入本目录后运行：
  .\dfs-admin.cmd

不带参数会进入中文交互终端。管理数据自动保存在本目录的 data 文件夹中，不需要配置；首次向导只询问 HTTP 设置。
标准整合包源目录不需要是完整游戏目录。目录里放什么就管理什么，可以只放 mods，也可以只放 config。

主菜单选择 [10] 可启动 Web 管理界面：
  http://127.0.0.1:18080/
Web 管理端只监听本机。远程服务器请使用 SSH 隧道，不要把 18080 直接开放到公网：
  ssh -N -L 18080:127.0.0.1:18080 <用户>@<服务器>
菜单 [9] 和 [10] 运行时按 Ctrl+C 会停止当前服务并返回主菜单。

第一次部署请先阅读本包中的 QUICKSTART.md；遇到远程部署、备份或故障时再查 DEPLOYMENT.md。

正式部署要点：
- 管理数据目录、标准源目录和玩家实例必须分开；不要把包含项目私钥的管理数据发给玩家。
- 项目 public-url 必须是玩家电脑可访问的公网 IP 或域名，不能把 127.0.0.1、localhost 或 0.0.0.0 发给玩家。
- 先发布玩家端程序和首个整合包版本，再制作玩家实例。
- 制作玩家实例时必须选择该下载包对应的历史发布；管理端会写入签名分发基线。
- 强制同步可按一级目录单独配置。配置的源目录缺失时拒绝发布；要发布空目录必须保留该空目录。
- HTTP 服务示例：
  .\dfs-admin.cmd serve --host 0.0.0.0 --port 8080
- 健康检查：
  http://127.0.0.1:8080/healthz

运行 .\dfs-admin.cmd --help 可查看全部参数式命令。
