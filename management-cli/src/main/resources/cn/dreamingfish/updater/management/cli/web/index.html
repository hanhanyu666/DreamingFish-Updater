导出外部托管目录

适用于普通 HTTP、对象存储（OSS）和 CDN

管理端会把当前项目转换成一份可以直接上传的静态目录。其中包含整合包更新、玩家端自更新、个性化内容、签名文件和内容对象；不会包含管理密码、对象存储密码或项目签名私钥。

上传时请保留目录结构：把导出目录中的全部文件原样上传到公开根目录，不要只上传 latest。上传完成后，项目中的“玩家端更新器访问地址”应填写该公开根地址，例如 https://update.example.com/。
已经分发过整合包时不要直接更换下载域名：旧玩家端会继续访问实例里原先绑定的地址。最稳妥的做法是始终使用自己的固定更新域名，只把该域名的解析或反向代理切换到新的对象存储/CDN；首次制作整合包则可以直接填写新的公开地址。

上传到 WebDAV / HTTP PUT

适合 WebDAV 网盘、NAS 和支持 PUT 的文件空间

管理端会先刷新静态目录，再从服务器直接上传。浏览器只负责发出管理指令；即使上传过程中关闭网页，已经开始的管理端上传仍会继续。远程地址使用账户时必须是 HTTPS。

上传到 OSS / S3 / R2

使用标准 S3 Signature V4，不额外安装云厂商 SDK

阿里云 OSS、AWS S3、Cloudflare R2、MinIO 等可使用这一入口。API Endpoint 用于管理端上传；玩家访问的公开域名请在项目设置中单独填写。Bucket 需要允许玩家匿名读取，或通过 CDN 提供公开读取。

怎么选择分发方式

下载流量由托管平台承担
HTTP 文件空间 / WebDAV适合已有网盘、NAS 或 WebDAV 服务的服主。上传导出目录后，确保玩家可以匿名读取。
对象存储（OSS / S3 / R2）按使用量计费，适合服务器带宽较小的情况。请开启公开读取或通过 CDN 暴露公开下载域名。
CDNCDN 不是另一套文件格式，而是给 HTTP 或对象存储加一层就近缓存。内容对象可以长期缓存；latest、presentation 和对应 .sig 应及时刷新。
