# [玩家 - 0.2.2][管理 - 0.2.7] 修复请求连接中断与 Windows 目录迁移

**本次只更新管理端与桌面版，玩家端保持 0.2.2。已经发布过 0.2.2 玩家端程序的服主不需要再次发布；尚未发布的服主，仍需发布它才能把上一版的玩家端修复交付给已有玩家。**

管理端与桌面版升级为 **0.2.7**，修复部分请求已经返回、但连接随后被关闭，导致下一次请求报网络错误的问题。玩家端保持 **0.2.2**，Bootstrap Agent 保持 **0.1.2**。

## 修复内容

- 管理接口和公共下载服务现在只在请求内容确实读取完毕后允许复用连接，避免扫描、发布、上传等操作偶发收不到响应头。
- 提前拒绝上传时，明确告知客户端关闭连接，不再让下一次请求误用即将关闭的连接。
- 保留慢上传与连接数量限制，不会为了保住连接而一直等待被拒绝的上传传完。
- 修复 Windows 同一目录使用不同路径写法时，数据迁移完成但连接记录仍指向旧目录的问题；继续保留源、目标不重叠及便携相对路径检查。
- 补充同一条 TCP 连接连续请求、完整上传、分块上传、拒绝不完整上传和主动关闭连接的回归测试。
- 发行脚本统一让 Maven 编译测试和打包使用指定的 Java 21，避免本机默认 Java 与实际发行运行环境不一致。
- CI 错误摘要包含具体失败用例，便于区分测试失败与依赖下载失败。
- Maven 依赖下载遇到连接重置或超时时最多重试两次，测试断言失败不重试；整包中文检查使用已有的 UTF-8 文件输入，并核对中文和表情字符。
