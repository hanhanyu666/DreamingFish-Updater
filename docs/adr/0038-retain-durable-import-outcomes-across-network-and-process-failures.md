# Retain durable import outcomes across network and process failures

管理导入在首次修改标准内容前保存可核对的意图、原文件及规则状态，恢复时验证双方指纹，再完成同一次已确认操作；持久收据决定提交事实。网络超时、浏览器切换和可重建暂存回收不能抹掉事实或触发重复导入；发生人工改动或归档缺失时保留材料并阻止冲突写入。

文件系统与 SQLite 没有共同的原子提交，因此仅靠异常回退不足以处理进程突然退出。选择可幂等重做和明确冲突状态，代价是保留小型收据、承担落盘开销并维护恢复协议。发布 / 外部上传任务重启后不自动重放，无法证明结果时保持待核对；源导入可用自己的收据证明最终结果。
