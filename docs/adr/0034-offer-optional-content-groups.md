# Offer optional content groups chosen by each player

Owners can put content that not every computer handles, such as shaders or visual effects, into named optional groups with a description and a default. Mods join a group by mod ID so renamed updates stay in it; other files and folders join by path, and content belongs to at most one group. Releases carry only groups that contain published files.

Each player switches whole groups in the updater. A group the player never touched follows the owner's current default, so changing the default later still reaches undecided players; an explicit choice persists until the player restores the default. A switched-off group moves its mods out of the game into local storage instead of deleting them, and a switch on an individual mod always wins over its group. When the owner stops publishing a mod they can instead choose “改为可选” to keep it available for players who still want it.

Decided on 2026-10-02.
