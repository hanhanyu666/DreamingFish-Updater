# Limit V1 client platform and launcher support

V1 supports Windows 10/11 x64 and launchers that can run a pre-launch command or accept JVM arguments, including PCL2, HMCL, and Prism Launcher. The official launcher, mobile platforms, and macOS are excluded so the first release can concentrate on reliable pre-game updates instead of cross-platform launcher integration.
