# 玩家端示例配置

`dreamhaven-player-pages.json` 是可以直接导入管理端“玩家端个性化内容”的页面配置。

导入后请依次完成：

1. 在页面中选择 JSON 文件并确认导入。
2. 点击“保存个性化设置”。
3. 扫描并发布一个新版本。

只有发布以后，玩家端才会收到新的页面和新闻。

## 玩家端音乐

管理端的“玩家端个性化内容”页面可以上传多首 MP3，并为每首歌填写玩家看到的名称。上传后请扫描并发布一个新的整合包版本；玩家更新时会自动把音乐下载到实例的
`.dreamingfish-bootstrap/music` 目录。单首音乐不能超过 20 MiB，音乐下载失败不会阻止整合包更新或启动。

玩家端会在界面右下方显示一个紧凑的音乐卡片，点击后可以选择歌曲、播放/暂停和开启循环。默认播放列表顺序就是管理端的排列顺序，循环设置会记住在玩家本机。

如果只是本地测试，也可以把一首 MP3 命名为 `startup-music.mp3`，放在以下位置之一：

```text
<Minecraft实例目录>/DreamingFishUpdater/startup-music.mp3
<Minecraft实例目录>/.dreamingfish-bootstrap/startup-music.mp3
```

旧版玩家端使用的 `bg_music.mp3` 和 `audio/bg_music.mp3` 路径仍然兼容。正式发布给玩家时，推荐使用管理端上传，这样所有玩家都能通过同一份发布清单获得音乐。
