# 独立桌面工作区设计

版本保持 0.2.0。此次重新设计整个桌面界面和操作组织，已有桌面构建保留用于比较。

## 界面结构

界面沿用第一版桌面工作区的分栏结构：窗口标题栏只显示连接与窗口按钮；最左侧是图标活动栏，默认只显示图标并在悬停时提示名称，可切换为显示文字，当前视图以浅色底块和左侧强调色竖条标出；旁边是可收起的项目栏，包含项目切换、发布状态、当前视图的目录或分区列表和当前发布版本；内容区顶部显示视图名称、项目名、操作记录和搜索命令。详情、发布说明和外观编辑以面板按需出现在右侧，批量操作在主内容区底部的浮动栏中完成。状态栏显示待发布数量、当前版本、文件统计、导入清单进度和下载服务。窗口变窄时项目栏和右侧面板依次收窄，900px 以下项目栏改为浮层。

文件页的文件夹树、可选内容和维护入口位于项目栏；收起项目栏或窗口较窄时，改为工具栏下方的目录标签。顶部工具栏提供后退、前进、上一级、路径、搜索、筛选和导入。选中文件后，底部浮动栏直接切换维护方式、加入可选内容或移出；双击、`Ctrl + I` 或“详情”打开右侧详情卡片。右键菜单提供同样的操作。工具栏随内容区宽度收起文字，搜索在窄时收成按钮并在聚焦时展开。

其他视图的分区列在项目栏中，内容区只显示当前分区名称；收起项目栏后，分区改为内容区顶部带下划线的标签页。表单中的二选一使用分段按钮。发布页先在主舞台查看差异，再在右侧发布卡片填写版本信息。部署、玩家端程序和外部托管进入发放工作区，部署页用三步状态说明当前进度。玩家端设计以真实预览为主舞台，编辑卡片位于右侧。文件导入进入从状态栏打开的导入清单；耗时操作、提示与错误显示在底部浮动提示中。

## 视觉与交互

采用桌面工具的分栏语言：活动栏、项目栏和状态栏共用外框颜色，内容区是一张 16px 圆角卡片，卡片内的面板以细线分隔；按钮与输入框 8px 圆角，卡片与菜单 12px，弹窗 16px，标签和筛选项为胶囊形。只有菜单、弹窗、提示和底部浮动栏这类浮层带阴影。文件按类型使用彩色图块图标；品牌以梦鱼小鱼为标志，空状态使用小鱼吐泡泡的插画，处理中提示为摆尾的小鱼。控件高度约 32px，工具栏约 52px，保留宽松的间距、表格列、右键菜单与快捷键，提供深浅主题。文件图标和其他操作图标均来自图标库。

所有操作连接真实管理服务。文件维护、发布签名、恢复校验与任务事务继续使用 Java 服务；桌面前端只负责呈现和调用。

## 实现

- 新的 Vue 桌面前端随应用打包，独立于服务器网页。
- 本机或 SSH 服务连接成功后，桌面端创建自己的 loopback 工作区服务，加载本地桌面资源，并将管理 API 请求转发到已选服务。
- API 转发绑定当前连接，不接受任意目标 URL；以每次连接的随机令牌限制访问，保留服务端认证和写入校验。密码不持久化，HTTP cookie 保存在本次连接的客户端内存中。
- 文件上传与部署包下载使用流式传输。连接断开时关闭所属工作区服务，不关闭远程服务器。
- 内置连接页仍拥有连接管理命令；工作区只拥有当前窗框操作。原网页和命令行继续使用原服务。

## 验收

检查完整的连接、项目创建、目录浏览、详情设置、批量操作、文件上传与暂存、发布、历史恢复、个性化预览、发放和设置流程；验证本机与远程使用同一套桌面界面，再生成供用户手动查看的桌面包。
