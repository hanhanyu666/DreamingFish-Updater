视觉规范同步调整了字号、辅助文字、控件高度、圆角、间距、固定表头和深浅主题变量。修正了旧样式的 900px 页面最小宽度、顶栏固定网格造成的重叠、侧栏溢出与窄窗口文件名被挤掉的问题。420×820 上传弹窗宽度 386px，没有水平溢出，底部按钮可见。

功能按文件工作区、文件传输、工作流程和 Java 应用服务划分，通过统一的 HTTP 传输边界调用后端。后续管理端桌面外壳可复用这些控制器和服务，文件维护、签名与认证继续在 Java 管理服务中执行。
