# 管理端桌面版实施计划

状态：实现与本机自动验收完成，等待用户手动查看界面。版本 0.2.0，验证平台 Windows x64。

## 用户流程

打开桌面端，选择本机管理或远程连接。本机可以使用默认管理数据目录，也可以选择已有管理端目录，继续维护原来的项目。远程可以填写 HTTPS 管理地址、本机转发地址，或选择已有 SSH 配置名称与服务器管理端口。

进入独立桌面工作区后，通过项目导航、文件列表和详情区维护内容；改动与版本、发放、玩家端设计和设置各有自己的工作视图。关闭窗口会收到托盘，重新打开可以返回原工作区。托盘提供工作区、连接选择和明确退出入口。

## 实现边界

- 新增 admin-desktop：Tauri 2 + Vue 3 / TypeScript 的连接库、独立工作区与 Rust 桌面进程管理。
- 桌面资源随程序打包，本机与远程使用同一套界面，通过每次连接的本机代理调用现有 Java 服务，保持 Web 与 CLI 的业务服务和数据格式。
- 新增 Java desktop 命令：只绑定 127.0.0.1 的系统分配端口，通过 UTF-8 JSON 标准输出报告就绪地址；标准输入关闭或收到退出请求时关闭所属 Web 管理进程。
- 桌面模式不覆盖已有 webHost / webPort 设置。已有 CLI / Web 实例及其下载服务继续按原方式管理。
- Java 管理核心、精简 Java 21 和 Bootstrap Agent 随桌面发行包提供；用户的管理数据、账户与项目密钥放在独立目录。
- 工作区在单独窗口运行，只能操作当前窗框；连接管理、目录选择与子进程管理命令只允许内置连接页调用，并同时检查窗口与来源。服务器提供业务数据，桌面界面来自内置资源。
- SSH 使用系统 OpenSSH 和用户已有配置、认证代理、known_hosts，保持主机密钥检查。连接信息只保存名称、地址、目录与端口，不保存账户密码或私钥。
- 工作区窗口禁用 Tauri 对拖放的拦截，提供桌面文件导入与任务面板；每个连接使用独立 WebView 数据目录，管理会话留在代理的内存中。
- 仅管理本程序创建的 Java / SSH 子进程。关闭窗口保留后台任务；退出对所属 Java 进程发送关闭请求，必要时有限等待后终止该子进程。

## 工作顺序

1. 实现并测试 Java 桌面进程入口、就绪握手、数据目录锁及部署资源定位。
2. 实现本机、地址、SSH 连接和连接记录，增加原生命令权限边界、错误处理与取消。
3. 实现工作区窗口、托盘、重复打开与退出，检查玩家端预览在桌面容器中的行为。
4. 增加可复现的构建与打包脚本，提供 Windows 便携 ZIP；构建环境支持时同时生成安装程序。
5. 用独立演示数据验证真实本机工作区、文件/文件夹浏览、上传暂存、发布预览、部署 ZIP、SSH 只读连接及退出清理。

## 完成条件

- 双击可启动，普通用户无需自行安装 Java。
- 不依赖开发服务器；发行包使用生产构建。
- 既有管理数据可以继续打开，默认端口被占用也可以启动桌面工作区。
- 本机和远程工作区的主要管理功能可用，远程网页不能调用本机原生命令。
- 关闭到托盘和明确退出行为一致，无所属进程残留，也不终止其他管理实例。
- 提供测试记录、实测包体积与实际桌面截图，更新使用文档和未发布更新日志。
